# Evidence files

The CPU-vs-DMA simulator-cycle chart is provided as an SVG so it renders directly in GitHub.

The waveform files are generated when the testbenches run:

- `build/dma_extended.vcd`
- `build/picorv32_dma.vcd`

Open them with GTKWave. The repository does not claim that a VCD is a performance graph; it is a signal-versus-time debugging trace. See [the output guide](../graph_and_output_guide.md).
