### CPU-vs-DMA simulation benchmark

The integrated PicoRV32 firmware testbench reported:

| Transfer size | CPU copy loop | DMA setup + transfer + polling |
|---|---:|---:|
| 16 bytes | 155 cycles | 258 cycles |
| 64 bytes | 551 cycles | 342 cycles |
| 256 bytes | 2,135 cycles | 720 cycles |

The testbench reported completion in **12,686 simulation cycles**. For the 256-byte case, the DMA path used approximately **66.3% fewer simulator cycles** than the CPU copy loop. For 16 bytes, DMA was slower because setup and polling overhead dominated. These are simulator-cycle measurements from this specific testbench, not physical hardware performance or throughput claims.
